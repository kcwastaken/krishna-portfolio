Mission Briefing

Built a comprehensive, end-to-end inference pipeline for real-time sign language translation. This system captures webcam feeds, extracts holistic keypoints, and translates sequences of motion into readable text on the fly.

Leveraged Spatiotemporal Neural Networks alongside Google's MediaPipe framework to capture sequential hand and body movements. The system currently achieves a 95% gesture accuracy across over 30 distinct, dynamic signs in real time.

Key Features

  • Real-time hand and body tracking via MediaPipe
  • 95% inference accuracy on dynamic gestures
  • Recognizes a vocabulary of 30+ distinct ISL signs
  • FastAPI integration for seamless backend handling
